# SINGE - Studies In Geography

Version 0.4.0 (see ../CHANGELOG.md). Older notes below that say v023 or v024 refer to builds made before version numbers (now 0.1.0).

SINGE is a Scored Game made with [EduGame Kit](https://github.com/togetherings/edugame-kit). To play it from this folder, run `edugame preview .` (add `--package world` for the World maps, `--lang fr` for French only); the kit makes the files the page needs (`edugame.js`, `edugame-config.js`). Each map can offer four game modes: Practice, Regions, Capitals and Flags (turned on or off per map).

## Folder layout
Three kinds of material, each in its own place: words in `lang/`, content (the maps) in `maps/`, and settings in `config.js` and `edugame.json`.

| Folder / file | What it is | Edit by hand? |
|---|---|---|
| `index.html` | page layout and colours (CSS) | sometimes |
| `edugame.json` | the version, languages, starting appearance (`options`), scoring, and the **packages**: which maps each zip has | **yes** |
| `config.js` | game-wide settings: tries before the hint, mode order, goals, skip, zoom defaults | **yes** |
| `lang/<code>.json` | ALL interface text in one language (buttons, hover text, messages, mode names, scoreboard and package names). `en.json` is the default; `_notes` in it say where some text is shown | **yes** |
| `js/game.js` | all game logic | rarely |
| `maps/<map>/shapes.js` | a map's SHAPES (outlines). Generated by `tools/map_generation.py` | no |
| `maps/<map>/settings.js` | a map's SETTINGS, in the default language: title, credit, zoom, orientation, pass mark, which modes are on, capitals, info, flags | **yes** |
| `maps/<map>/lang/<code>.json` | the map's text in another language (title, region and capital names, info) | **yes** |
| `maps/<map>/flag.svg`, `maps/world/flags/` | the menu card's picture, and flag images for Flags mode | add files |
| `icon.svg` | the icon | - |
| `tools/` | Python scripts that make the shapes files (only needed to add or reshape a map) | - |
| `tests/` | `python -m tests.e2e_browser` plays every package in a browser | - |

The kit builds `edugame.js`, `kolibri-game.json` and the rest into each zip, so don't add those here. `tools/`, `docs/`, `data/`, `tests/` and the notes are left out of the zips (`exclude` in `edugame.json`).

## Options
The kit puts a header at the top of the page: the game's title (the package's, like "Studies In Geography: Countries"), and an **Options** button. Its panel has Appearance (Light, Dark, or Auto: follows the device) and Language (each language written in itself). The appearance shows straight away; the language changes on Apply. On the Kolibri Games games page, which shows the title already, the header has only the button.

The appearance is kept on the device. The language is kept in the learner's save, so it follows them in Kolibri. A learner who hasn't chosen gets Kolibri's language (on the Kolibri Games games page), then the browser's, then English. `"options": {"theme": "light"}` in `edugame.json` sets the appearance a new user starts with.

## Languages
**Interface text.** Every piece of text the game shows is in `lang/<code>.json`, one entry per text. To add a language, run `edugame translate . sw` (this copies the English text into `lang/sw.json` and adds `sw` to `languages` in `edugame.json`), put the language's own name in `_language`, and translate. Keep the `{words in braces}`: the game fills them in. Entries with `one` / `other` give separate wording for singular and plural (languages with more forms can add `few`, `many`...). Anything missing falls back to English; `edugame check .` lists what's missing. See the kit's docs/LANGUAGES.md.

**Map text.** The settings files (`maps/<map>/settings.js`) are written in the default language. A translation of one map is a small file, `maps/<map>/lang/<code>.json`, holding only text: `name`, `blurb`, `credit`, `variants` (the name and blurb of each way a map is listed, like `world` and `world_all`), and per region (keyed by the region's default-language name) `name`, `capital`, `info`, `capital_info`. Coordinates, flags and goals are never duplicated. Anything left out shows the settings file's text. See `maps/us/lang/fr.json` (a partial translation). When a player chooses a language other than the default and a map has no file for it, that map's card shows "English only" (the default language's name). Saved scores do not depend on language.

The settings files are in the default language (the first in `languages` in `edugame.json`).

## Add a new map
1. Get boundary data (GeoJSON, or a Shapefile with its .dbf) in longitude/latitude.
2. `cd tools` then
   `python3 map_generation.py boundaries.geojson --id my_country --out ../maps/my_country/shapes.js --name-property NAME_1`
   (use `--script` for maps that need special handling - see `tools/sierra_leone.py`, or `tools/us.py`
   for a map drawn with a projection and with distant regions moved closer).
3. Copy `maps/sierra_leone/settings.js` to `maps/my_country/settings.js` and edit it.
4. Add the map to a package in `edugame.json`: its folder to the package's `files` (`"maps/my_country/*"`) and its name to the package's `config.maps`. Add scoreboard names for its boards (`my_country`, `my_country_capitals`, `my_country_flags`) to `scoring.boards.names`, with the words in each `lang/<code>.json` (`board.my_country`...).
5. Optional: put a picture (such as a flag) in `maps/my_country/` and set `image: 'maps/my_country/flag.svg'` in the settings file; it appears on the map's menu card, scaled to fit.

Run `edugame preview . --package <package>` and check the console (F12) for warnings about mismatched names.

## Pass mark and SCORM
Each scored mode (Regions, Capitals, Flags; not Practice) has its own accuracy goal, `pass_accuracy`.
Defaults are in `config.js` (Regions 80, Capitals 0, Flags 0); a map can override them in its settings
file, e.g. `pass_accuracy: { regions: 80, capitals: 70 }`. A goal of 0 means the mode is not required
and no goal is shown on its menu button. SCORM `lesson_status` is "incomplete" from the first visit and
becomes "passed" once every goal above 0 (in every map) has been reached by the best accuracy. If there
are no goals at all, the status stays "incomplete". A menu button with a goal shows "Goal: N%" and
changes colour once the goal is met, along with the best accuracy, best time and times completed.

Saved per board in SCORM `suspend_data` by EduGame Kit's helper: `{"_v":1,"sierra_leone":[best accuracy, best time (s), times played]}`. Board ids are the map id (Regions), `<id>_capitals` and `<id>_flags`; never change a map's id once people have played it.

**0.3.0 change.** A round now counts (is kept, and sets SCORM "passed") when its accuracy reaches that mode's goal; a goal of 0 means every round counts. Before 0.3.0, "passed" needed every goal in every map to be met. A round below the goal still adds to "times played" but does not replace the best result.

## Packages and the kit
`packages` in `edugame.json` lists the zips: each has an `id`, a `title` and `description` (words in `lang/`, like `package.countries`), its `files` (its map folders), and `config.maps`, the maps on its menu. A map is its folder's name, or `{"id": ..., "file": ..., "scope": ...}` to list one map more than once: the World map is listed twice, once for UN countries (`world`) and once for everything (`world_all`). `package_files: ["maps/*"]` keeps each map only in the packages that list it.

```bash
edugame build . -o dist                  # dist/singe-countries-<version>.zip, dist/singe-world-<version>.zip
edugame build . --package world --lang fr
edugame build . --each-language          # one zip per package and language
```

All packages share the game id `org.togetherings.singe`, so scoreboards combine them. The Continents package will be added once it has maps, starting with Africa.

## Skipping
The right-arrow button skips the current prompt; skipped prompts come back only after all the others
have been shown once. The left-arrow button returns to the most recently skipped prompt. Turn it on or
off per map with `skip` in the settings file (`true`, `false`, or per mode `{ regions: true, capitals: false }`),
or for every map with `skip_enabled: true / false` in `config.js` (`null` lets each map decide).

## Flags mode
Put an image path in a region's `flag` setting (e.g. `flag: 'maps/my_country/bo.png'`), add the image to the
package, and set `flags: true` in the map's `modes`. The game shows a flag and the player clicks its region.

## World map (and later continent maps)
`maps/world.js` is generated from Natural Earth data (public domain: ne_10m_admin_0_countries) by `tools/world.py`;
`maps/world/settings.js` (capitals and options) was first written by `tools/world_settings.py` from Natural Earth's
populated places, and is hand-edited from then on. Antarctica is left out.

- **Projection**: Miller cylindrical, which repeats sideways, so the map can scroll round the world without end
  (`infinite_scroll` in config.js, or per map in its settings file; `false` gives the map edges). Two copies of the world
  are drawn side by side and the view wraps. The Caribbean and Pacific boxes under the map (a separate svg) never scroll or zoom.
- **Scope** (`scope` in maps/world/settings.js): `'un'` = the 193 UN members plus Vatican City and Palestine (parts such as
  Alaska, French Guiana or Svalbard belong to their country; everything else is drawn grey and is not asked about).
  `'all'` = every country and territory, with far-away parts as regions of their own (Alaska, Hawaii, French Guiana,
  Guadeloupe, Martinique, Réunion, Mayotte, Svalbard, Jan Mayen, Bonaire, Saba, Sint Eustatius, Christmas Island,
  Cocos (Keeling), Tokelau, Kaliningrad). The two scopes save their scores separately (`world` and `world_all`).
- **Capitals** only exist for UN members, Vatican City, Palestine, and places other states recognise (Taiwan, Kosovo,
  Western Sahara, Northern Cyprus). Where there are several capitals the most populated city was used for now
  (see the list printed by `world_settings.py`); change it by editing the capital in the settings file.
- **Tiny countries and island chains** get a circle (`marker_px`, `circle_ratio`) while they are too small to click; the
  circle disappears when you zoom in far enough. In Practice mode the circle shows both the country and its capital.
- **Full Screen** button: the code is still there but the button is off (Kolibri has its own full page mode). Set `fullscreen_button: true` in config.js to show it again (in a small header at the top of the page).
- **Size**: the map is sized to the window height. On a window at least `fit_all_min_height` tall (a 1080p screen) the map AND the boxes fit together; on a shorter one (a 768p laptop) just the map fits and the page scrolls to the boxes. `page_width` is the widest it may get.
- **Layout**: on the world map the game bar is laid over the top of the map. The boxes have their titles inside them and no spare padding.
- **Shared circle**: a capital with `with: 'Vatican City'` in the settings (Rome) is the same circle as that region in Practice mode. Vatican City has no capital (Regions only). Brazzaville/Kinshasa and Nicosia/North Nicosia are moved a little apart (see `NUDGE` in `tools/world_settings.py`).
- **Outlines**: shapes can have an outline path `s` (see `tools/world.py`) so that the seam between the two copies of the world (Russia, Fiji) and merged leased areas draw no stray lines. A region is highlighted in every place it is drawn.

### Planning for continent and sub-continental maps
Every world region has `cont` (continent) and `sub` (UN sub-region) in `maps/world.js`. A continent map can be generated by
`tools/world.py` with a filter on those values and its own crop (lat/lon window), then use the same engine (`wrap: false`
gives edges). Nothing else in the game needs to change.

Data licence: Natural Earth is in the public domain; borders are its de facto lines, which not everyone agrees with.

## World map notes (v024 changes)
- **Boxes**: the Pacific box sits under South Africa and western Australia (`PACIFIC_RIGHT_LON`), the Caribbean box on the same line over the south-east Pacific (`CARIBBEAN_RIGHT_LON`); a few small islands off Chile/Argentina may be under it.
- **More parts split off** (All mode only; in UN mode they stay in their country, like Alaska): Easter Island, Galapagos, Tasmania, Newfoundland, Baffin Island, Okinawa Islands, Orkney, Shetland, Hebrides, Corsica, Crete, Sardinia, Sicily, Canary Islands, Balearic Islands, Azores, Madeira, Sakhalin (`SPLITS` in `tools/world.py`; add a line to split off another).
- **Clicking a part for its country** (Regions and Flags games, All mode): when the country is asked for and a far-away part of it is clicked, the part flashes yellow, is not counted, and a message says to click the main area (`feedback.not_main` in lang/*.json).
- **Crimea** is a region of its own (`BREAKAWAY`): grey in UN mode. **Western Sahara** is the whole territory (the part Morocco controls was cut off Morocco along 27 deg 40' N; grey in UN mode). **Bosnia and Herzegovina**'s east border was moved out over the gap Natural Earth leaves for Republika Srpska (`fill_bosnia`). **Turkey** is called Tuerkiye (Türkiye).
- **Nudges** only apply on the most zoomed-out levels: `nudge_zoom_levels` (default 2) in the map settings. Zoomed in further, circles are back at their real places (capitals: `nudge: [lat, lon]` next to the real `lat`/`lon`; region circles: `mkn` in the shapes file). The boxes never zoom, so their circles stay moved.
- **Flags**: `tools/world_settings.py --flags <folder with xx.svg>` links `maps/world/flags/<iso2>.svg` to every region that has one (a few parts use their country's neighbour file: `FLAG_FILE`). Regions without a flag are left out of the Flags game; the script prints the list. The flag has no border, so non-rectangular flags look right.
- **Default scope** of the world map is now `'all'` (set `scope: 'un'` in maps/world/settings.js for the UN game).
- **Phones**: a wide map held upright shows "turn your device sideways" (can be dismissed). Browsers only allow a real orientation lock in full screen, so the game asks (`screen.orientation.lock`) but cannot force it.

## World map notes (v023)
- **Size**: no height cap any more (`max_map_height` is optional). The map is as big as the window allows; with `fit_all_min_height: 800` the map AND the boxes fit a 1080p window together, on shorter windows the map alone fits.
- **Boxes (insets)**: the Pacific box sits under Africa and Australia, the Caribbean box under the south-east Pacific, both starting on the same line just under the lowest land above the Pacific box (`tools/world.py`: `PACIFIC_RIGHT_LON`, `CARIBBEAN_RIGHT_LON`, `CARIBBEAN_HEIGHT`). They overlap the bottom of the map. Inside a box everything is solid (the map underneath cannot be seen or clicked); around the boxes the map shows and works as usual.
- **Removed (uninhabited)**: U.S. Minor Outlying Islands, Heard & McDonald, Clipperton, South Georgia & S. Sandwich, French Southern & Antarctic Lands, Coral Sea Islands, British Indian Ocean Territory, Ashmore & Cartier (`DROP`), Jan Mayen, Bouvet, Marion & Prince Edward, Ascension (`PIECE_DROPS`). Akrotiri and Dhekelia are merged into Cyprus (`MERGE_INTO`). Saint Helena and Tristan da Cunha are separate regions (`SPLITS`).
- **Annobon** is drawn but is not part of Equatorial Guinea's highlight (`DECOR`: drawn, never highlighted or clicked).
- **Combined places** (`COMBINE` in `tools/world.py`): Saint Martin + Sint Maarten and Sint Eustatius + Saba are one shape and one circle, but each keeps its own entry (capital, info, flag) and its own question in every mode. The shape changes colour once both are answered; the hover label shows the answered ones. In the shapes file the second place has `twin: '<first place>'`. Their capitals and info notes are in `tools/world_settings.py` (`CAPITAL_EXTRA`, `INFO`).
- **Nudges**: circles of close neighbours are moved apart: capitals in `NUDGE` (`tools/world_settings.py`) and region circles in `NUDGE_MARKER` (`tools/world.py`): Hong Kong/Macau, Qatar/Bahrain, Samoa/American Samoa, Congo, Cyprus.
- **Linked hover**: pointing at a circle (region or capital) in a box also highlights it on the main map (both copies of the world), and the other way round.
- **World map halos** (wide invisible outlines for tiny regions) are no longer used: the circles do that job (Wallis and Futuna's halo covered its neighbours).
- Lakes: Natural Earth `ne_10m_lakes` (public domain): lakes that cross borders plus the Great Lakes (`LAKE_FORCE`); `LAKE_SKIP` leaves out Lake Champlain and Lake Nasser.
- Rebuild: `python3 tools/world.py <ne_10m_admin_0_countries.json> --lakes ne_10m_lakes.geojson --out maps/world/shapes.js`, then `python3 tools/world_settings.py maps/world/shapes.js ne_10m_populated_places_simple.shp --out maps/world/settings.js` (needs numpy, scipy, opencv-python, matplotlib).

## Sierra Leone notes (0.2.0)
`maps/sierra_leone.js` has 18 districts. The shapes are built by `tools/sierra_leone.py` from the HDX chiefdom (ADM3) and section (ADM4) files:
```
cd tools
python3 map_generation.py sle_admin3.geojson sle_admin4_em.geojson --id sierra_leone --out ../maps/sierra_leone.js --script sierra_leone.py
```
The rules for the unofficial changes (new districts Bandajuma and Kpanguima, the new Jahn Chiefdom, the Gbanti Kamaranka and Nieni splits, the Falaba spelling) are at the top of that file. The same rules make the GeoJSON package in `data/sierra_leone/` (`tools/make_sierra_leone_package.py`). Capitals and info are in `maps/sierra_leone/settings.js`.
